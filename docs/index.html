このチェッカーについて
このツールで、高得点・満点を取れば採択されるというものではありません。自分の経験と覚悟を、自分の言葉で論理的に表現するための練習ツールです。採択の最終判断は事務局の複数名が応募文章を読み、平均点で決まります。その判断プロセスに直接介入する手段はありません。このアプリができるのは、「あなたの文章があなたらしい物語になっているか」を確認する支援だけです。
