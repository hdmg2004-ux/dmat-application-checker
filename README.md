# DMAT若手枠 応募文章チェッカー

日本DMAT隊員養成研修（厚生労働省調整枠・若手枠）の応募文章作成を支援するツールです。

**制作：東京医療減災Labo**　／　**内部利用限定**

---

## ツールの目的

高得点・満点を取れば採択されるというものではありません。自分の経験と覚悟を、**自分の言葉で論理的に表現するための練習ツール**です。

採択の最終判断は事務局の複数名が応募文章を読み、平均点で決まります。その判断プロセスに直接介入する手段はありません。このツールができるのは「あなたの文章があなたらしい物語になっているか」を確認する支援だけです。

---

## 使い方

1. ブラウザでhttps://hdmg2004-ux.github.io/dmat-application-checker/　を開く
2. **受講希望理由**（500字以内）を入力
3. **キャリアプラン**（500字以内）を入力
4. 入力と同時に以下の3つの診断が自動で更新される

| 診断 | 内容 |
|---|---|
| **5軸診断** | 原体験・実績・限界の論拠・将来像・還元視点を0〜3点で自動スコアリング |
| **整合チェック** | 受講希望理由とキャリアプランの時間軸の役割分担を確認 |
| **物語度** | 文章の固有性（具体的な年・数字・感情語・資格名）と汎用性のバランスを0〜100で算出 |

---

## 応募文章の基本構造

採択文章はすべて**1,000字の物語**として構成されています。医師・看護師に限らず、業務調整員を目指す方の合格者も、この構造で書いています。

```
受講希望理由（500字）= 過去 → 現在
  ① 具体的な原体験（災害・臨床での出来事、または現場に関われなかった経験＋感情）
  ② 現在の立場と実績（職種・勤務先・経験年数・資格）
  ③ なぜ今DMATか（現状の限界を論理的に）
  ④ DMATで何を得てどう活かすか

キャリアプラン（500字）= 現在 → 未来
  ① 最終目標（1文で宣言。DMATとして、所属先でチームを率いる立場を目指す姿勢が伝わると強い）
  ② 段階的なステップ（取得→インストラクター→統括→事務局等）
  ③ 自施設・地域・国への具体的な貢献
  ④ 覚悟・姿勢（締めの1文）
```

業務調整員を目指す方へ：原体験は「処置ができなかった」でなくてよい。「現場を知らないまま設計している」というギャップや、「関わりたくても資格がなく関われなかった」という挫折も、そのまま原体験になります。

---

## 5軸診断の考え方

DMATはチーム活動です。各隊員が所属先でリーダーとなれる人材を育てるという趣旨から、④将来像・整合チェックのコメントには「チームを率いる立場」への言及を含めています。ただし採点ロジック自体には影響しません（コメント文言のみの反映）。

- ①原体験・②実績・③限界の論拠 → **受講希望理由**と対応
- ④将来像・⑤還元視点 → **キャリアプラン**と対応

## 技術仕様

- スタンドアロンHTML（外部依存：Chart.js CDNのみ）
- サーバー不要・APIコストなし
- 全判定はクライアントサイドJavaScriptで完結
- Chart.js 4.4.1（レーダーチャート描画）

キーワードリスト（災害名・感情語・限界語・役職名等）の詳細は `DMATチェッカー_キーワード一覧_v7.md` を参照。
